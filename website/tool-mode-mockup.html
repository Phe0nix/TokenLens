Design intent for final implementation

  • Show locked Pro features inline with clear Pro badges instead of hiding everything.
  • Keep Free usable: inspect, layout, and accessibility preview remain visible.
  • Reserve time-saving power workflows for Pro: measure, advanced history, premium exports, and theme controls.
  • Use one consistent badge system across tabs, export modal, and history toolbar for clarity.
