CSS & Spacing Architecture

Popup z-index: 10 (main content)
Box Inspector z-index: 15 (floats above popup)
Measurement Badge z-index: 12 (between popup & inspector)
Overall: Measurement never blocks inspector, inspector never blocks popup
Position Strategy:
  • Popup: position: fixed; left: 20px; top: 20px (keeps it visible)
  • Box Inspector: position: fixed; right: 20px; top: 20px (opposite corner, no overlap)
  • Measurement Badge: position: fixed; bottom: 60px; left: 50% (center bottom, above demo elements)
  • Result: All three coexist without blocking each other
